How to export your Gemini conversations:
  1. Go to myaccount.google.com
  2. Tap Data & Privacy
  3. Scroll down to Download your data
  4. Select only Gemini Apps Activity
  5. Set delivery to Send download via email
  6. Set frequency to Export once
  7. Set file type to ZIP and size to 1 GB
  8. Click Create export
  9. Wait for Google's email, then download the ZIP
  10. Upload that ZIP file directly below — no need to open it
